# Screenshot checklist

Chrome Web Store image requirements (check against the latest dashboard docs
before submitting).

## Sizes

- [ ] **Screenshots:** 1280×800 or 640×400 PNG/JPEG, 24-bit, no alpha.
      Provide **3–5**. First screenshot is the most important.
- [ ] **Store icon:** 128×128 PNG (already at `store/icons/icon128.png`).
- [ ] **Promotional tile (optional):** 440×280 PNG/JPEG, no alpha.
- [ ] **Marquee (optional):** 1400×560 PNG/JPEG, no alpha.

## Screenshots to capture

1. [ ] **Live transcript** — side panel open during a meeting, several
       speaker-tagged lines visible, recording dot green, timer running.
2. [ ] **Rolling summary** — panel showing an AI summary while the meeting is
       still in progress.
3. [ ] **Final notes** — summary + decisions + action-items table after ending
       the meeting.
4. [ ] **Starting capture** — toolbar action clicked with a short callout
       pointing at the side panel.
5. [ ] **Meeting history** — list of past meetings in the panel.

## Capture checklist

- [ ] Use a realistic demo meeting (no real personal data).
- [ ] Dark side panel is legible at 100% zoom; no clipped text.
- [ ] Hide bookmarks bar and any unrelated extensions.
- [ ] Uniform window size across screenshots.
- [ ] No browser devtools, debug banners or console output visible.
- [ ] Each image is under the store file-size limit (verify in dashboard).
- [ ] Add a short localized caption for each screenshot if localization is
      offered.
